STUDENT INFORMATION & BILLING SYSTEM - BCA MINI PROJECT
=======================================================
TECHNOLOGIES: HTML, CSS, JavaScript, Browser LocalStorage
NO XAMPP / PHP / MYSQL / INTERNET REQUIRED.

HOW TO RUN:
1. Extract the ZIP.
2. Open the student_billing_browser folder.
3. Double-click index.html (Chrome, Edge or Firefox).
4. Use Students tab to add student records.
5. Use Billing & Payments tab to record fee payments and print receipts.
6. Use Reports tab to view balances, print reports and export backups.

PROJECT MODULES:
- Student registration and management (add, search, edit, delete)
- Course and year details
- Fee billing, payment entry, receipt printing
- Basic fee reports and browser backup/restore

REFERENCE:
Adapted from the user-provided Student Information and Billing System
project report (originally VB.NET and MySQL). This is a simplified
browser-based BCA mini-project implementation.

IMPORTANT:
- Data is stored in the browser's LocalStorage for this website/file origin.
- Opening the same files from a different browser, computer or location may
  show different/empty records. Export JSON backups regularly.
- Clearing browser site data can erase the records.
- This is an offline educational demonstration, NOT a secure production
  system, and does not process real online payments.
- Student deletion also deletes their payment records.
- The receipt reflects a manually recorded payment, not a bank confirmation.
